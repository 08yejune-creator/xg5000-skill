# xg5000-skill

LS ELECTRIC XG5000의 XGI PLC 프로젝트 파일(`.xgwx`)을 **XG5000 없이** 읽고 쓰는 [Claude Code](https://claude.com/claude-code) 스킬입니다.

`.xgwx`는 공개 문서가 없는 바이너리 형식이라 레더를 XG5000 밖에서 다룰 방법이 마땅치 않습니다. 이 스킬은 파일 구조를 분석해 정리한 문서와 파이썬 스크립트를 담고 있어서, Claude에게 "이 레더 읽어줘", "이 렁 고쳐줘"라고 요청할 수 있습니다. 스크립트만 따로 써도 됩니다.

## 할 수 있는 것

- **읽기**: 모듈 구성, 레더(네트워크별 접점·코일·타이머), 변수표를 텍스트로 출력합니다.
- **쓰기**: 파이썬으로 적은 렁 목록에서 `.xgwx`를 만듭니다. CPU, 모듈 구성, 프로젝트 설정은 템플릿 파일에서 가져오고 레더와 로컬 변수표만 교체합니다.
- **검증 절차 안내**: XG5000의 프로그램 검사와 시뮬레이터 쓰기로 결과를 확인하는 순서가 `SKILL.md`에 있습니다.

## 설치

파이썬 3 표준 라이브러리만 사용합니다.

```bash
git clone https://github.com/08yejune-creator/xg5000-skill ~/.claude/skills/xg5000
```

## 사용법

Claude Code에서는 `.xgwx` 파일을 주고 말로 요청하면 됩니다. 스크립트를 직접 실행할 수도 있습니다.

```bash
# 읽기 (파일을 바꾸지 않음)
python3 scripts/read_xgwx.py 프로젝트.xgwx

# 쓰기 (템플릿은 그대로 두고, 이미 있는 출력 파일은 덮어쓰지 않음)
python3 scripts/write_xgwx.py examples/motor_start_stop.py --template 기존프로젝트.xgwx -o 새프로젝트.xgwx
```

렁은 `+`(병렬), `*`(직렬), `!`(NC 접점)로 적습니다.

```python
INPUT_ADDRESSES = {"시작버튼": "%IX0.0.0", "정지버튼": "%IX0.0.1"}
OUTPUT_ADDRESSES = {"모터": "%QX0.2.0", "가동램프": "%QX0.2.1"}

PROGRAM = [
    ("모터 자기유지", [
        ("coil", "모터", "(시작버튼+모터)*!정지버튼"),
    ]),
    ("모터가 5초 돌면 램프 점등", [
        ("ton", "가동지연", "모터", 5000),
        ("coil", "가동램프", "가동지연.Q"),
    ]),
]
```

읽은 결과는 이렇게 나옵니다.

```
네트워크 1
  행   1: NO:시작버튼@1 │down@3 NC:정지버튼@4 COIL:모터@94
  행   2: NO:모터@1 │from@3
```

## 지원 범위와 한계

- **확인한 환경**: XGI-CPUE 프로젝트 하나입니다. 50개 네트워크 레더를 생성해 XG5000 프로그램 검사(오류 0개)와 시뮬레이터 쓰기·런까지 통과했습니다. 실제 PLC에 써서 시험하지는 않았습니다.
- **쓰기 지원 요소**: NO, NC, 코일, TON, 설명문입니다. 셋/리셋 코일, 펄스 접점, 다른 펑션 블록은 아직 만들 수 없습니다.
- **읽기 한계**: 분석하지 못한 요소가 나오면 `미확인 요소` 오류를 내고 멈춥니다.
- **템플릿**: 레더와 변수가 들어 있는 기존 프로젝트로 시험했습니다. 빈 새 프로젝트는 확인하지 않았습니다.
- **미확인**: XGK, XGB 프로젝트는 확인하지 않았습니다.

## 주의

- LS ELECTRIC과 관계없는 비공식 도구이며, 파일 형식은 직접 분석한 결과라 틀린 부분이 있을 수 있습니다.
- 생성한 파일은 반드시 XG5000에서 프로그램 검사와 시뮬레이터로 확인하세요. 파일이 열린다고 올바른 것은 아닙니다.
- 실제 설비에 쓰기 전에는 동작과 안전을 직접 확인하세요. 비상정지 같은 안전 기능을 이 도구의 결과에만 의존하면 안 됩니다.
